# План MVP на 5 часов — 3 человека + агенты

**Цель демо:** на НОВОЙ истории человек загружает фото и голосом рассказывает о переезде.
Агент уточняет детали, появляются карточки людей. После следующего ответа человек связывается
с ещё одним событием. Глава собирается, и из неё можно включить голос рассказчика.

**Уже готово (каркас):** весь дизайн; бэкенд с API; три агента с промптами, валидацией и мок-режимом;
оркестратор; хранилище; SpeechKit-обёртка; журнал агентов. Фронт получает состояние с сервера,
но действия на экранах пока имитированы в `app.js` — их и нужно подключить к API.

## Как работать с агентами (обязательно)

Каждый работает в Claude Code (или Codex) в своей ветке. `CLAUDE.md` в корне агент читает сам: там
устройство проекта, контракт и правила. Стартовый промпт для своей зоны лежит в вашем Issue —
скопируйте его агенту целиком.

- Ветка `masha/…`, `liza/…`, `max/…`. Маленькие PR в `main` раз в 40–60 минут, перед PR `git pull --rebase`.
- Все трое правят `app.js`, но разные функции (см. таблицу). Не переформатируйте файл целиком.
- Поменять контракт (`models.py`, `docs/contract.md`) можно только после сообщения в чат.
- Для проверки у агента есть `MOCK=1` и Swagger на `/docs`. Перед PR: полный проход в браузере.

## Вне MVP

Несколько рассказчиков об одном событии, семейные вещи, исторический контекст, архивный поиск, древо с раскладкой,
Hindsight и семантическая память, авторизация (демо однопользовательское).
