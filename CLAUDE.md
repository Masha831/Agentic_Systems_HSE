# Помню — инструкции для coding-агентов

Сервис записывает голосовые воспоминания и собирает из них историю. Продуктовая постановка — `docs/mvp.md`,
план и зоны ответственности — `docs/plan.md`, API — `docs/contract.md`.

## Запуск и проверка
- `.venv/bin/uvicorn backend.app.main:app --reload --port 8000` из корня; UI — http://localhost:8000, Swagger — `/docs`.
- `MOCK=1` в `.env` — агенты и речь без Яндекса (сценарии из `backend/app/seed.json`). Без ключей мок включается сам.
- Сброс БД: `rm -rf backend/data`.
- Проверяй изменения в браузере, а не только curl: полный проход «создать историю → ответить → собрать главу».

## Устройство
- Frontend — vanilla JS без сборки. `app.js` хранит состояние в `S` (формат `window.POMNU` из `data.js`)
  и перерисовывает экраны функциями `*HTML()`. Серверное состояние приходит из `GET /api/state` (загрузчик в `index.html`).
  Все запросы — через `frontend/assets/api.js`. Мутации: вызвать API → положить ответ в `S` → `rerender(...)`.
- Backend — FastAPI. Агенты наследуют `agents/base.py::Agent`: `build_prompt` → `llm.structured` (JSON по pydantic-схеме)
  → `postprocess` (починка id/ссылок) → запись в trace. У каждого агента есть `mock()`.
- LLM — Yandex AI Studio через OpenAI SDK (`llm.py`), модель `gpt://<folder>/<YANDEX_MODEL>`.

## Правила
- Не менять формы данных из `models.py` и `data.js` без согласования: на них сидят все трое.
- Исходный ответ (`Source`) не переписывается агентами; связи (`Person.links`) всегда со ссылкой `src` на источник.
- Двух людей с одинаковым именем не объединять молча — создавать `clarify`.
- Агенты не выдумывают факты; Интервьюер задаёт один вопрос и уважает `declined`.
- Тексты интерфейса — на русском, в стиле существующих. Не трогать CSS и разметку дизайна без нужды.
- Ключи только в `.env` (он в `.gitignore`). Никаких токенов в коде и коммитах.
- Правь только функции своей зоны в `app.js`, не переформатируй файл целиком (конфликты у троих).
